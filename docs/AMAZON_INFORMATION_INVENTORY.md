# Amazon Information inventory

Status: implemented lifecycle inventory

Owner: RizPoint LLC security owner

Last verified: 2026-08-29

## Policy basis and RizPoint ceiling

The current [Amazon Key Security Control Guidance](https://developer-docs.amazon.com/sp-api/docs/guidance-to-address-key-security-controls-in-sp-api-integration) says non-PII data is retained only as long as strictly necessary with documented justification. It does **not** currently publish a universal 18-month non-PII limit. The current [Data Protection Policy](https://sellercentral.amazon.com/solution-provider/policy?policyType=DPP) requires secure deletion of all live instances within 30 days of the earliest applicable deletion notice, authorization revocation, loss of entitlement, or service termination.

RizPoint nevertheless applies the prompt-requested **18-calendar-month maximum** as a stricter internal ceiling for ordinary Amazon SP-API observations. A shorter provider/contractual rule wins. No legal-hold feature exists; a lawful exception requires a reviewed code/configuration change and written legal basis before retention can be extended.

## Classification vocabulary

| Class                    | Meaning                                                       |
| ------------------------ | ------------------------------------------------------------- |
| `AMAZON_INFORMATION`     | Value or payload obtained from Amazon SP-API.                 |
| `DERIVED_FROM_AMAZON`    | Calculation/snapshot whose input includes Amazon Information. |
| `RIZPOINT_BUSINESS_DATA` | RizPoint workflow state that is not an Amazon source value.   |
| `USER_SUPPLIED`          | Facts, notes, assumptions, or commands entered by the user.   |
| `SUPPLIER_PRIVATE_DATA`  | Supplier files, rows, quotes, and costs.                      |
| `SECURITY_LOG`           | Payload-minimized security/audit metadata.                    |
| `CREDENTIAL`             | Refresh tokens/provider secrets and encrypted envelopes.      |
| `OTHER_PROVIDER_DATA`    | Licensed non-Amazon source information such as Keepa.         |

## Derived-data rule

RizPoint does not assume that transformation makes Amazon Information exempt. A derived record is purged or minimized when it contains source values, a high-fidelity projection, or enough dimensions to reconstruct expired Amazon values. A decision record may retain only non-provider-specific workflow facts such as decision, owner, date, formula/version identifiers, and the fact that evidence was removed. New snapshot/aggregate models must be added to this inventory before release.

Supplier files, user inputs, and security logs are outside Amazon-source lifecycle deletion. Their independent confidentiality, retention, and security policies still apply.
