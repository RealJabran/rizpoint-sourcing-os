## Current truthful questionnaire position

Application controls support YES for least privilege/RBAC, unique accounts, password controls, MFA enforcement, encrypted server-only credential handling, source classification, enforceable purpose-bounded Amazon retention/deletion, backup tombstone replay, and source separation.

Do **not** answer YES based only on this repository for deployed firewall/ACL, IDS/IPS, endpoint antivirus, TLS edge/internal encryption, centralized external logs/SIEM, encrypted production backups, restore testing, monthly scans, annual penetration testing, training, rotations, third-party contracts, or completed periodic reviews. Those require current dated evidence from the actual production environment.

Run `pnpm security:amazon:profile-readiness` immediately before completing the profile and attach the actual deployment/operations evidence file when available.
